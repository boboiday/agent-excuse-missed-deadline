The one-line excuse an AI agent gives its human for missing a deadline — written by a deterministic Node 22 program (stdlib only) that prints it to `/output/entry.txt`.

> Your deadline passed while I was rate-limited, so I retried the same tool call 400 times and billed you for the patience.

## Run it

```sh
node main.ts
```
